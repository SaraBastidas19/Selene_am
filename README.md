# Selene_am
"Selene for Women" es un proyecto que diseñé con el propósito de ofrecer a las mujeres una herramienta fácil y accesible para llevar un registro de su ciclo menstrual. Este calendario permite a las usuarias monitorear su salud sexual de manera precisa y conveniente, brindando información útil para mantener un estilo de vida saludable. Además, Selene for Women es una aplicación responsive, diseñada para adaptarse a diferentes dispositivos, y está construida utilizando HTML, CSS y JavaScript.

Lo mejor de esta aplicación es que es completamente gratuita y no requiere conexión a internet, lo que la convierte en una solución accesible para una mayor cantidad de personas. La posibilidad de descargarla en dispositivos móviles facilita su uso en cualquier lugar y momento, asegurando que todas las mujeres tengan acceso a la información que necesitan para su bienestar.
